## After Cloning the Project run these commands in your Terminal:

### Backend Setup
```Bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Frontend Setup
```Bash
cd frontend
npm install
```

### To run the Application as a Whole
```Bash
./start.sh
```
If you ever want to retrieve updates from the original repository, you can use:


```bash
git fetch upstream
```
You can then inspect the changes before deciding whether to merge them.
